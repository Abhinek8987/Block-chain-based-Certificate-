# Blockchain Certificate Verification System

A comprehensive decentralized certificate verification platform built with React.js, Node.js, Solidity, and IPFS.

## 🏗️ Project Structure

```
blockchain-certificate-verification/
├── frontend/                 # React.js + Tailwind CSS
├── backend/                  # Node.js + Express.js
├── smart-contracts/          # Solidity + Hardhat
├── docs/                     # Documentation & Diagrams
├── tests/                    # Test cases
└── deployment/               # Deployment scripts
```

## 🚀 Features

- **Multi-role Authentication**: Admin, Institution, Student, Verifier
- **Certificate Management**: Upload, store, and verify certificates
- **IPFS Integration**: Decentralized storage using Pinata
- **QR Code Generation**: Easy verification via QR scanning
- **Blockchain Verification**: Immutable certificate records
- **Real-time Dashboard**: Role-based UI components

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, Ethers.js
- **Backend**: Node.js, Express.js, MongoDB
- **Blockchain**: Solidity, Hardhat, Polygon/Ethereum
- **Storage**: IPFS (Pinata), MongoDB
- **Authentication**: JWT tokens

## 📋 Quick Start

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables
4. Deploy smart contracts
5. Start backend and frontend servers

Detailed setup instructions in `/docs/setup-guide.md`
